# Apocaunloader 1.3.0

Identical guns now keep separate loaded ammo counts. Firing, reloading or unloading one gun no longer changes the magazine
you see when switching to another copy of that model.

- Each physical gun retains its magazine and hammer/chamber state across switching and save/load.
- Works with the game's slots and Apocapocket's additional slots, without requiring Apocapocket.
- Previously tracked guns retain their ammo when dropped and picked up again.
- Switching during an unload finishes the outgoing gun's transfer; loading cancels the old unload safely.
- Existing shared rounds go to the first gun drawn of each type. Other copies start empty to preserve the ammo total.
- Backpack reserve ammo stays shared by caliber.

The `Enabled` option controls unloading and backpack overflow protection. Per-gun magazine tracking stays active while the
plugin is installed, including when this option is off, so toggling it cannot discard or duplicate loaded rounds.

Install the new DLL and restart the game. Magazine metadata is stored with the character save under
`Apocaunloader.Magazines`; loading a save without this key migrates its native weapon-type pools.
